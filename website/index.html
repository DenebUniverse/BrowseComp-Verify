The central question

An agent can find an answer.
Can it reliably tell if an answer is right?

Solving ≠ verifying

Web search agents increasingly judge other agents’ answers. We study whether they can derive the criteria, retrieve evidence, and make a reliable judgment—without a gold answer or a predefined rubric.

01 / Motivation

Search ability is only part of the story.

Solving starts with a question. Verification starts with the same question plus a candidate answer. Knowing where to search helps with both, but judging a candidate also requires deciding which constraints matter and whether the evidence is sufficient.

TakeawayEvaluate verification directly. Solver performance alone does not describe an agent’s ability to judge answers.

02 / The task

Derive the test. Find the evidence. Make the call.

In self-derived verification, the agent receives a question and a candidate answer. It has retrieval tools, but receives no gold answer, solver trajectory, or predefined rubric. It must work out what makes the candidate correct.

01

Derive

Identify the question’s necessary constraints.

02

Verify

Search for evidence and check each constraint.

03

Decide

Accept or reject the candidate answer.

03 / Main results

Rejecting wrong answers is not enough.

Many agents do much better at rejecting incorrect candidates than accepting correct ones. GPT-v5.2-Thinking-high, for example, scores 99.04% on incorrect candidates but only 20.39% on correct candidates. Its overall accuracy is 59.90%.

TakeawayA verifier must recognize correct answers as well as reject incorrect ones. Always inspect both class accuracies alongside Overall.

04 / Prompt calibration

A smaller gap is not the same as a better verifier.

The strict prompt requires explicit support for every constraint; missing evidence leads to rejection. A relaxed prompt allows a more holistic judgment. This reduces rejection of correct answers, but also lets more incorrect answers through.

TakeawayRelaxing the prompt rebalances errors. Whether it improves verification must be checked against Overall accuracy.

05 / Implications

Reliable verification needs grounded judgment.

Our audit of 100 failed cases assigns 135 error tags across seven categories. Retrieval and constraint-handling failures dominate: finding evidence is only useful if the agent interprets it faithfully against the question.

01

Missing evidence ≠ a false claim.

Failure to retrieve support can make a strict verifier reject a correct candidate. Search coverage and the decision rule interact.

02

Meaning goes beyond wording.

Literal matching can miss semantically equivalent evidence. Verification requires grounding constraints in what a source actually says.

A human comparison needs matched cases.
